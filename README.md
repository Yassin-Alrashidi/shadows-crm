# Shadows CRM
Mobile-first CRM for the Shadows team: tickets, leaves, resignations, clients, dashboard. Navigation is the owl-eye lens dial at the bottom: drag left or right, release to open.

Runs in demo mode (data in the browser) until `js/config.js` has a Supabase URL and anon key. For the shared backend, run `sql/schema.sql` in the Supabase SQL editor, turn off "Confirm email", and fill `js/config.js`. The first account to sign up becomes admin.
